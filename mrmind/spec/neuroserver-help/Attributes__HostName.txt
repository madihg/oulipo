NeuroScript Attributes: HostName 

 ?HostName

 ?HostName is provided as a part of NeuroServer's HTTP connection.
If Reverse DNS is enabled (on the Connect tab of the Project Options dialog), it is set by default to the name of the machine
from which the user is logging in.
