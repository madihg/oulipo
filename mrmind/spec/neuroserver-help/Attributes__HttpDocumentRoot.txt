NeuroScript Attributes: HttpDocumentRoot 

 ?HTTP_DOCUMENT_ROOT

 ?HTTP_DOCUMENT_ROOT is provided as a part of NeuroServer's HTTP connection.
It is imported by the same mechanism that imports all other HTTP variables.

In a typical installation of NeuroServer, it will never have a value.
