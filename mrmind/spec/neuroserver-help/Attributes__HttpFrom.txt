NeuroScript Attributes: HttpFrom 

 ?HTTP_FROM

 ?HTTP_FROM is provided as a part of NeuroServer's HTTP connection.
It is a reference to a standard HTTP variable, imported in the same way that
all HTTP variables are imported.

In a typical installation of NeuroServer, this will never have a value.
