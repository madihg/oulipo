NeuroScript Attributes: HttpReferer 

 ?HTTP_REFERER

 ?HTTP_REFERER is provided as a part of NeuroServer's HTTP connection.
It is a reference to a standard HTTP variable, imported in the same way that
all HTTP variables are imported.

This variable is set to the URL that the user was last browsing before
coming to the vRep.
