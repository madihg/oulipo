NeuroScript Attributes: HttpScriptName 

 ?HTTP_SCRIPT_NAME

 ?HTTP_SCRIPT_NAME is provided as a part of NeuroServer's HTTP connection.
It is imported by the same mechanism that imports all other HTTP variables.

This attribute will not have a value in normal configurations of NeuroServer, because there
is no CGI script associated with the user's interactions.
