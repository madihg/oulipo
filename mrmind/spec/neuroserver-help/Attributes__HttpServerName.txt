NeuroScript Attributes: HttpServerName 

 ?HTTP_SERVER_NAME

 ?HTTP_SERVER_NAME is provided as a part of NeuroServer's HTTP connection.
It is imported by the same mechanism that imports all other HTTP variables.

By default, it is set to the numeric IP address of the machine that is running NeuroServer.
