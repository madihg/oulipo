NeuroScript Attributes: HttpUserAgent 

 ?HTTP_USER_AGENT

 ?HTTP_USER_AGENT is provided as a part of NeuroServer's HTTP connection.
It is a reference to a standard HTTP variable, imported in the same way that
all HTTP variables are imported.

This variable is set to the name of the browser the user is using.
