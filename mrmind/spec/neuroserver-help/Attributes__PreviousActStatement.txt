NeuroScript Attributes: PreviousActStatement 

 ?PreviousActStatement

 The ?PreviousActStatement attribute is set whenever
the ?ActStatement attribute was set on the previous user utterance.
It is set to the same thing that the ?ActStatement was set to on the
previous user utterance.
