NeuroScript Attributes: PreviousAnyQuestion 

 ?PreviousAnyQuestion

 The ?PreviousAnyQuestion attribute is set whenever
the ?AnyQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?AnyQuestion was set to on the
previous user utterance.
