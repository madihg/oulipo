NeuroScript Attributes: PreviousAnyStatement 

 ?PreviousAnyStatement

 The ?PreviousAnyStatement attribute is set whenever
the ?AnyStatement attribute was set on the previous user utterance.
It is set to the same thing that the ?AnyStatement was set to on the
previous user utterance.
