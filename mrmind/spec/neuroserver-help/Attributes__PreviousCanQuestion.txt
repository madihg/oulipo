NeuroScript Attributes: PreviousCanQuestion 

 ?PreviousCanQuestion

 The ?PreviousCanQuestion attribute is set whenever
the ?CanQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?CanQuestion was set to on the
previous user utterance.
