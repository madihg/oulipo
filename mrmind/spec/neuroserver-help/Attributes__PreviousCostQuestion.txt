NeuroScript Attributes: PreviousCostQuestion 

 ?PreviousCostQuestion

 The ?PreviousCostQuestion attribute is set whenever
the ?CostQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?CostQuestion was set to on the
previous user utterance.
