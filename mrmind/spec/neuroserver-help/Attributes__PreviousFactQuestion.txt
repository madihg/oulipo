NeuroScript Attributes: PreviousFactQuestion 

 ?PreviousFactQuestion

 The ?PreviousFactQuestion attribute is set whenever
the ?FactQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?FactQuestion was set to on the
previous user utterance.
