NeuroScript Attributes: PreviousFactStatement 

 ?PreviousFactStatement

 The ?PreviousFactStatement attribute is set whenever
the ?FactStatement attribute was set on the previous user utterance.
It is set to the same thing that the ?FactStatement was set to on the
previous user utterance.
