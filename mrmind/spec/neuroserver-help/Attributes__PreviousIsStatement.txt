NeuroScript Attributes: PreviousIsStatement 

 ?PreviousIsStatement

 The ?PreviousIsStatement attribute is set whenever
the ?IsStatement attribute was set on the previous user utterance.
It is set to the same thing that the ?IsStatement was set to on the
previous user utterance.
