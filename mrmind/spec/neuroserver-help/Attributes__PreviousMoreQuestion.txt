NeuroScript Attributes: PreviousMoreQuestion

 ?PreviousMoreQuestion

 The ?PreviousMoreQuestion attribute is set whenever
the ?MoreQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?MoreQuestion was set to on the
previous user utterance.
