NeuroScript Attributes: PreviousObtainQuestion

 ?PreviousObtainQuestion

 The ?PreviousObtainQuestion attribute is set whenever
the ?ObtainQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?ObtainQuestion was set to on the
previous user utterance.
