NeuroScript Attributes: PreviousOtherQuestion

 ?PreviousOtherQuestion

 The ?PreviousOtherQuestion attribute is set whenever
the ?OtherQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?OtherQuestion was set to on the
previous user utterance.
