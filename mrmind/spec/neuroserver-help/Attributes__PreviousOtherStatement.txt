NeuroScript Attributes: PreviousOtherStatement

 ?PreviousOtherStatement

 The ?PreviousOtherStatement attribute is set whenever
the ?OtherStatement attribute was set on the previous user utterance.
It is set to the same thing that the ?OtherStatement was set to on the
previous user utterance.
