NeuroScript Attributes: PreviousReasonQuestion

 ?PreviousReasonQuestion

 The ?PreviousReasonQuestion attribute is set whenever
the ?ReasonQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?ReasonQuestion was set to on the
previous user utterance.
