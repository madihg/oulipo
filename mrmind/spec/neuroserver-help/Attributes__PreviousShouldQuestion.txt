NeuroScript Attributes: PreviousShouldQuestion

 ?PreviousShouldQuestion

 The ?PreviousShouldQuestion attribute is set whenever
the ?ShouldQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?ShouldQuestion was set to on the
previous user utterance.
