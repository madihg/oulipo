NeuroScript Attributes: PreviousTimeQuestion

 ?PreviousTimeQuestion

 The ?PreviousTimeQuestion attribute is set whenever
the ?TimeQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?TimeQuestion was set to on the
previous user utterance.
