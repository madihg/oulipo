NeuroScript Attributes: PreviousTimeStatement

 ?PreviousTimeStatement

 The ?PreviousTimeStatement attribute is set whenever
the ?TimeStatement attribute was set on the previous user utterance.
It is set to the same thing that the ?TimeStatement was set to on the
previous user utterance.
