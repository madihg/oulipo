NeuroScript Attributes: PreviousWantStatement

 ?PreviousWantStatement

 The ?PreviousWantStatement attribute is set whenever
the ?WantStatement attribute was set on the previous user utterance.
It is set to the same thing that the ?WantStatement was set to on the
previous user utterance.
