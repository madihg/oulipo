NeuroScript Attributes: PreviousWhatIfQuestion

 ?PreviousWhatIfQuestion

 The ?PreviousWhatIfQuestion attribute is set whenever
the ?WhatIfQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?WhatIfQuestion was set to on the
previous user utterance.
