NeuroScript Attributes: PreviousWhoQuestion

 ?PreviousWhoQuestion

 The ?PreviousWhoQuestion attribute is set whenever
the ?WhoQuestion attribute was set on the previous user utterance.
It is set to the same thing that the ?WhoQuestion was set to on the
previous user utterance.
