NeuroScript Attributes: UserIsConsole 

 ?UserIsConsole

 The ?UserIsConsole attribute is "TRUE" if the user is
logged in from the NeuroServer console. If the user is 
logged in over the web or some other interface, the ?UserIsConsole 
attribute has no value.

This attribute is primarily useful for debugging purposes; it
is also useful in applications where the console user has
special privileges.
