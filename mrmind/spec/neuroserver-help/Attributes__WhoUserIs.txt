NeuroScript Attributes: WhoUserIs 

 ?WhoUserIs

 The ?WhoUserIs attribute is set by NeuroServer so that it can
recognize user utterances as belonging to a particular user even if running
without cookies.

 Note: Running without cookies is not recommended.
