An Introduction to Bot-Building using NeuroStudio

 An Introduction to Bot-Building Using NeuroStudio

This tutorial is a step-by-step tutorial in the use of Neurostudio and 
bot building. It introduces the major features of NeuroStudio and,
at the same time, build the framework of a simple, conversational bot. 

This tutorial assumes that you have already installed Neurostudio and 
have entered a valid registration key upon starting it for the first time. If
you have not, then do so before proceeding.
